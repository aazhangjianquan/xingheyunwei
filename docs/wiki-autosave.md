# 知识库编辑与自动保存

阅读文档、新建文档和编辑文档时，点击遮罩或弹窗外的空白区域不会关闭窗口。使用右上角关闭按钮或底部“关闭”按钮退出。

已有文档在停止输入约 1 秒后自动保存到服务器。保存时保留文档当前状态，已发布文档的修改仍会对有访问权限的成员生效；每次实际变更保留历史版本，无变化不重复生成版本。保存请求期间可以继续输入，新输入的内容会排队保存，不会被前一个请求的响应覆盖。

新文档在当前浏览器持续保留草稿，填写标题、内容分类和正文后点击“保存文档”正式创建。在编辑已有文档时，如果暂时清空必填项，内容也会保留本地，补齐后继续同步。

编辑器会显示正在保存、已保存或同步失败。网络或服务器暂不可用时，本地草稿仍保留，后台自动重试；网络恢复或点击“重试同步”也可继续保存。尚未同步时刷新或关闭浏览器会显示浏览器离开提醒；重新进入同一知识库的新建/编辑页面，可恢复草稿。本地草稿按账号、空间和文档隔离，只在当前浏览器中保留，清除网站数据会删除这些草稿。可使用“下载草稿”另存 Markdown 文件。

打开文档和恢复已有文档的草稿前，仍需通过后端权限验证。自动保存也重新校验空间成员及编辑权限，账号或空间权限变化不能绕过校验。发现权限撤销后，清除当前编辑窗口与对应草稿。

每次同步携带读取时的文档版本。其他成员或窗口已提交新版本时，服务器返回冲突，不覆盖新版本。编辑器保留当前草稿并暂停同步，可下载草稿，读取服务器最新版本后合并修改。

本次沿用现有文章、版本及权限表，无需新增 SQL、目录挂载或环境变量。部署时同时更新 API、Worker 和前端镜像。
