# 星河项目协作平台使用手册

编写日期 2026年11月2日　｜　适用对象 平台成员 审批人 执行人员 管理员

本手册帮助你完成项目申请、审批、执行回填和知识协作。操作说明依据当前平台功能编写；实际可用菜单、数据和按钮取决于账号角色、项目岗位、知识库成员权限及已发布的审批流程。访问地址和个人账号由本单位管理员提供。

## 从这里开始

1. 登录平台，打开右上角头像，核对姓名并修改初始密码。
2. 在「项目管理」确认自己参与的项目及岗位。没有可选项目时，先请管理员或有权限的项目负责人配置。
3. 根据工作内容进入「资源申请」「变更管理」「私有化交付」或「License 管理」，选择关联项目后提交。
4. 审批人和执行人员到「我的审批」处理分配给自己的任务；申请人在原模块查看流程和结果。
5. 将个人笔记保存在自己的知识库；需要协作时新建知识库，由负责人邀请指定成员。

### 按职责查阅

| 你的工作 | 建议先看 |
| --- | --- |
| 首次登录和日常使用 | 第1章 登录与工作台 |
| 维护项目及参与成员 | 第2章 项目管理 |
| 提交申请或处理待办 | 第3章 通用申请与我的审批，再查第4至7章 |
| 写文档或共享资料 | 第8至9章 知识库 |
| 管理账号与部门职责 | 第10章 用户部门与角色 |
| 配置审批资源规格和通知 | 第11至13章 管理员配置 |
| 查发送结果或操作记录 | 第14章 通知记录与操作日志 |
| 删除停用或排查问题 | 第15至16章 |

**先理解三个概念。** 账号角色决定可承担的职责；项目岗位决定在具体项目中承担的职责；审批任务决定某一轮、某一节点由谁处理。三者需要匹配。看到一张单据，不代表可以审批；看到项目，也不一定具有申请资格。

**资料使用。** 本手册不提供共享账号、默认密码或应用密钥。请使用个人账号操作；截图求助时遮盖密码、License Key 和客户敏感信息。

## 1 登录与工作台

### 登录平台

1. 在浏览器打开管理员提供的平台地址，使用自己的用户名和密码登录。
2. 登录后从左侧菜单进入相应模块；手机或窄屏页面可先展开左上角菜单。
3. 使用结束后点击左下角退出按钮，尤其是在公用电脑上。

平台使用账号密码登录，飞书用于接收通知。收到飞书链接后，仍需登录平台，并通过业务权限检查。

### 修改姓名和密码

点击右上角头像或左下角姓名，打开「个人资料与安全」。所有成员，包括管理员，都可以修改自己的姓名和登录密码。

- 在个人资料页修改姓名并保存。用户名、所属部门和角色由管理员维护。
- 在密码页填写当前密码、新密码和确认密码，再提交修改。
- 新密码须为12至128位，并包含大写字母、小写字母、数字、特殊字符四类中的至少三类；不能与当前密码相同。
- 按修改成功后的提示重新登录。忘记当前密码时，联系管理员处理。

### 阅读工作台

工作台汇总资源、变更、交付和License申请数量，并展示与你权限范围相符的进度信息。先查看待处理数量，再进入「我的审批」确认具体任务；查看申请结果则进入对应业务模块。

**数量口径。** 工作台的申请数量、业务列表的筛选结果和「我的审批」的待办数量含义不同。一次申请可以经过多个节点并产生多人的任务，不能把申请数当作审批任务数。

### 看不到内容时先检查什么

| 页面表现 | 应对方法 |
| --- | --- |
| 提示此账号已停用 | 联系管理员启用，修改密码不能解除停用 |
| 登录过期或要求重新登录 | 重新登录后再打开原页面 |
| 没有系统配置等菜单 | 确认自己的角色是否具备该模块权限 |
| 列表为空 | 清空搜索和状态筛选，再核对项目或空间成员权限 |
| 页面提示加载失败 | 按页面提示重试；持续失败时记录时间和错误原文交管理员 |

## 2 项目管理

资源、变更、私有化交付和License申请统一关联项目。项目目录用于组织成员与岗位，申请单用于记录具体工作，两者应分别维护。

### 查找自己的项目

进入「项目管理」，查看项目总数、启用数和停用数。可以按项目名称、部门或成员搜索，也可以组合所属部门和项目状态筛选，点击「重置筛选」恢复列表。非管理员看到的是自己有权查看的项目范围。

### 创建项目

1. 管理员点击「创建项目」，填写项目名称、所属部门及状态。
2. 在项目岗位下勾选成员。同一岗位可以分配多人，一个成员也可以承担多个岗位。
3. 至少保留一名项目经理，点击「保存项目」。
4. 请相关成员重新打开申请页面，检查项目是否可选。

**候选成员为空时。** 先到「用户与权限」为成员授予相应角色，再回到项目分配岗位。停用账号不能作为新的有效岗位成员。成员全局角色撤销后，旧项目岗位可能显示「需调整」，应移除或重新配置。

### 谁可以维护项目

| 身份 | 维护范围 |
| --- | --- |
| 管理员 | 创建项目，修改名称部门和状态，维护全部项目岗位 |
| 项目中的项目经理 | 维护该项目的其他岗位成员 |
| 本部门项目经理负责人 | 维护本部门项目的项目经理岗位 |
| 本部门商业化负责人 | 维护本部门项目的销售／售前岗位 |
| 本部门技术负责人 | 维护本部门项目的产品开发岗位 |
| 本部门智能体开发负责人 | 维护本部门项目的智能体开发岗位 |

项目经理的任免由管理员或相应部门的项目经理负责人处理。仅获得部门岗位管理能力，不会自动取得这些项目的申请资格或全部业务单据的查看权限。

### 项目停用

项目不支持删除。管理员在「维护项目」中将状态改为停用，保留项目及岗位记录，停止将其用于新的业务申请。普通成员申请时，需要拥有与账号角色匹配的项目岗位；管理员可以申请全部启用项目。

## 3 通用申请与我的审批

### 从提交到完成

申请人提交 → 按条件进入审批节点 → 审批通过 → 执行回填或生成License → 流程完成。

具体节点、处理人和条件分支以本类单据已发布的流程为准。进入单据详情，可查看流程轮次、节点、处理人、审批方式、意见与处理时间。进行中的单据继续使用提交时的流程版本。

资源、变更和交付列表中，管理员、运维负责人、管理者及运维人员可查看全部未删除记录；其他成员按本人申请、有效项目岗位、审批参与情况等权限查看，部门负责人还可查看本部门申请。License和知识库使用各自更严格的规则，详见对应章节。

### 申请人如何跟进

1. 在业务模块新建申请，选择启用项目，补齐必填字段后提交。
2. 确认出现单据编号和流程信息；不要把尚未提交的表单当成已保存的申请。
3. 在原模块通过搜索、状态筛选和分页找到申请，打开详情跟踪当前节点。
4. 被驳回时阅读意见，点击修改重提入口，修正后重新提交。新一轮使用当时最新发布的流程，原轮次和意见保留。

### 审批人如何处理

1. 打开「我的审批」，按每页10、20或50项查看分配给自己的待办。
2. 打开任务，核对关联项目、申请信息、附件和当前节点。
3. 填写审批意见后点击「同意」；需要修改时点击「驳回修改」，建议清楚写出问题和补充要求。
4. 成功处理后，该待办不再出现在待处理列表；历史意见在单据详情中查看。

「我的审批」只显示当前分配给本人的待处理任务，管理员也不能在这里查看他人的全部待办。申请人不能审批自己的申请；管理员身份不会自动取得某张单据的审批任务。

### 多人审批与执行

| 审批方式 | 节点何时通过 |
| --- | --- |
| 全部同意 会签 | 当前节点全部处理人同意 |
| 任意一人同意 或签 | 任意一名处理人同意，其余待办关闭 |
| 任意N人同意 | 同意人数达到N，其余待办关闭 |

节点仍在待处理时，任一有效驳回会退回申请人，并关闭本轮尚未完成的相关任务。执行人员也从「我的审批」进入，实际完成操作后填写结果，点击「完成回填」或「完成交付」。平台记录审批和交付过程，资源开通及系统变更仍由执行人员完成。

## 4 资源申请

资源申请用于说明所需资源、使用期限及容量依据。资源类型和规格字段由管理员维护，选择不同类型后，表单会显示对应字段。

### 提交资源申请

1. 进入「资源申请」，点击新建入口，选择关联项目。
2. 选择运行环境，例如POC、测试或生产，再选择资源类型。
3. 按该类型要求填写规格。标记为必填的规格字段必须完成。
4. 设置开始日期和结束日期，结束日期不能早于开始日期。
5. 填写「资源用途」和「容量依据」，根据需要填写端口开通及白名单需求。
6. 核对后提交，在详情中检查编号、规格和流程信息。

### 规格填写示例

以下为配置示例，实际字段以平台当前资源目录为准。

| 资源类型示例 | 可能配置的规格 | 填写关注点 |
| --- | --- | --- |
| ECS | CPU核数 内存 容量 | 写明需求数量及单位，例如2核4GB |
| APIKEY | 厂商 用途 额度 | 明确服务厂商；申请规格无需粘贴实际密钥 |
| 数据库 | 引擎 版本 存储容量 | 说明兼容要求及数据增长预估 |

资源用途应说明服务对象、承载业务及所需环境。容量依据建议给出预计用户量、并发、数据量或测试规模，便于审批人判断规格是否合理。

### 查看审批和回填结果

- 在列表中搜索申请，结合状态筛选和分页定位单据。
- 打开详情查看本次提交的资源类型、规格名称和值，以及审批记录。
- 分配到执行节点的运维人员填写实例、连接说明或交付结果，再点击「完成回填」。

资源目录日后调整，不会把历史申请中的规格自动替换为新定义。申请人与执行人员应以该单据保存的规格和回填结果核对交付。

**没有资源类型时。** 联系管理员在「系统配置 → 资源类型」启用资源类型并保存。不要用不相符的类型代替。

## 5 变更管理

变更单用于说明要解决的问题、维护窗口及影响范围。当前版本在申请阶段填写问题说明和附件，实施方案、回滚方案在运维执行／回填阶段填写。

### 申请人提交变更

1. 进入「变更管理」，点击新建变更入口并选择关联项目。
2. 填写「变更单名称」，选择变更类型和环境。
3. 按实际情况选择运维负责人；具体待办处理人仍由审批流程解析确定。
4. 填写维护窗口开始和结束时间，结束时间须晚于开始时间。
5. 在「变更问题说明」写清变更背景、问题现象、目标和影响范围。
6. 在「变更附件」添加问题截图、依据或方案文档，核对后提交。

### 问题说明建议

可按以下顺序写一段完整说明：当前出现什么问题；影响哪个系统或客户；本次计划改变什么；预计影响范围和需要协同的人员。涉及停机或业务中断时，应明确说明。

**示例。** 某项目生产网关证书即将到期，需要在维护窗口内更新证书并验证访问。变更涉及网关服务，预计产生短时连接重建；请相关业务人员配合验证。示例仅用于说明填写方式。

### 执行人员回填

1. 审批流转到执行节点后，执行人员从「我的审批」打开任务。
2. 填写实际「实施方案」，说明操作步骤和关键验证点。
3. 填写「回滚方案」，说明失败时的恢复步骤和恢复验证方法。
4. 填写「变更执行结果」，说明是否成功、验证情况及遗留事项。
5. 核对后点击「完成回填」。上述三项在完成变更执行时均需填写。

### 附件与驳回

变更附件支持常见Office文档、PDF、TXT、CSV、Markdown、RTF，以及JPG、JPEG、PNG、GIF、WebP图片。单个文件不超过20MB，具体操作见第6章。

被驳回后由申请人修改重提，新一轮重新审批；实施方案、回滚方案和执行结果将在新一轮执行阶段重新填写，不能直接沿用旧执行结果作为新一轮完成记录。

## 6 私有化交付与附件

### 创建交付单

1. 进入「私有化交付」，点击创建入口并选择关联项目。
2. 填写交付项目名称、客户名称，选择云环境和交付阶段。
3. 选择部署方式、计算资源与加速卡类型。
4. 按需填写网络说明、数据库白名单、ECS安全组和交付备注。
5. 在表单内添加项目附件，再提交申请。
6. 跟踪审批进度；分配到执行节点的人员填写交付结果，点击「完成交付」。

当前交付流程不要求回填数据库账号或密码。数据库白名单属于网络访问要求，请勿将账号密码填到白名单或备注中。

### 创建时选择和上传附件

- 点击「添加附件」或拖拽文件，支持多选。提交前可以移除或清空已选文件。
- 创建表单中的文件处于「待提交」，正式提交申请后才自动上传。
- 提交后检查每个文件是否显示「已上传」。失败时可点击「重试」或「继续上传」，不要只凭单据创建成功判断附件已经保存。
- 只有单据创建人可以上传；具有该单据查看权限的成员可以预览和下载。

### 文件范围

| 使用位置 | 支持的文件 |
| --- | --- |
| 私有化交付 | DOC DOCX XLS XLSX PPT PPTX PDF TXT CSV MD RTF |
| 变更管理 | 上述文档，以及JPG JPEG PNG GIF WebP图片 |
| 单个文件限制 | 不超过20MB，不能上传空文件 |

### 在线预览和下载

打开单据详情，在附件行点击「预览」或「下载」。Office首次预览需要转换，稍候即可；预览失败或版式不合适时，点击「下载原文件」，使用本地软件打开。在线预览用于阅读，不能直接编辑Office附件。

附件保存在私有存储中，平台按单据权限校验访问；普通成员不需要填写MinIO地址或存储密钥。文件未上传成功前，请保留本地原件。创建表单未提交时，不要依赖刷新页面恢复已选文件。

## 7 License管理

License申请统一关联项目，最终审批节点达到通过条件后由平台调用授权工具生成密钥。申请人无需自行运行命令。

### 提交授权申请

1. 进入「License 管理」，点击申请入口并选择启用项目。
2. 填写客户名称、授权产品和租户ID，确认与实际系统一致。
3. 设置授权到期时间。表单按北京时间填写，到期时间必须晚于当前时间。
4. 填写账号数和智能体数；如业务允许不限数量，填写「-1」。
5. 说明申请用途并提交，在详情查看审批进度。

### 最终审批与密钥生成

最终审批可以配置多人，采用全部同意、任意一人同意或任意N人同意。达到阈值时自动生成License。若授权工具报错，应保留错误原文交管理员排查，并重新核对申请状态，避免重复创建相同申请。

**谁能看到密钥。** 仅申请人和实际完成最终审批、触发生成的那一名审批人可以查看生成的License Key。管理员或License管理者可以管理申请记录，但不会因此自动获得密钥查看权限。

| 最终节点示例 | 实际可查看密钥的人员 |
| --- | --- |
| A B C全部同意，C最后同意 | 申请人和C |
| A B C任意一人同意，B同意 | 申请人和B |
| A B C任意两人同意，A后B同意 | 申请人和B |

### 查看和复制结果

- 列表支持关键词、状态筛选和每页10、20或50条分页。
- 申请人可在已生成单据中点击「查看 Key」，再使用复制按钮。
- 浏览器限制剪贴板时，可在有权限的详情中手动选中复制。
- 非密钥可见人员会看到受限提示；最终节点的其他参与人也不一定可见。

被驳回后，申请人根据意见修改重提。若历史单据显示「关联项目并补充审批」，按提示选择有权限的启用项目并提交审批，完成新流程后再查看密钥。

## 8 知识库阅读与写作

知识库以空间保存文档，分类可以按项目、产品或主题自由填写。分类用于查找资料，访问范围由空间成员权限独立控制。

### 找到知识库和文档

首次进入默认使用自己的个人知识库，仅本人可见。左侧「知识库目录」可搜索库名，按「全部可访问」「我负责的」「与我共享的」及分类筛选。选择知识库后，在右侧搜索文档标题或正文，并按草稿、已发布、已归档筛选。

### 新建知识库

1. 点击「新建知识库」，填写名称、分类和说明。
2. 新建库的访问范围为「指定成员」。创建后你自动成为负责人。
3. 需要共享时，在「空间设置 → 成员管理」添加成员，操作见第9章。

个人知识库已自动创建，不需要另建一个名为“个人”的分类来获得隐私保护。指定成员知识库也不会因“公共”字样或分类名称而向全员开放。

### 创建文档

1. 选择有写作权限的知识库，点击「新建文档」。
2. 填写标题、内容分类和正文，选择所属空间与文档状态。
3. 标题最多180个字符，内容分类最多60个字符；根据输入框计数控制长度。
4. 点击「保存文档」正式创建。新文档首次保存前只保留当前浏览器中的草稿。

正文支持Markdown标题、加粗、列表、表格、引用、链接和代码块。编辑时点击“预览”检查排版，点击“编辑”继续写作，切换不影响自动保存。文档详情和历史版本均显示排版后的正文。

### 阅读修改和版本

点击卡片打开文档，使用右上角或底部「关闭」退出。阅读和编辑时，点击弹窗外空白处不会关闭文档。具有编辑权限时，可修改文档并查阅历史版本；编辑已有文档不能更换所属空间。

草稿、已发布和已归档均继承知识库的访问范围。共享知识库中的草稿也对该库有查看权限的成员可见。需要仅自己可见的草稿，请先写在个人知识库。

## 9 知识库成员与自动保存

### 成员权限

| 身份 | 阅读和历史版本 | 创建文档 | 编辑文档 | 管理成员 |
| --- | --- | --- | --- | --- |
| 个人库本人 | 自己的库 | 可以 | 自己的库 | 无成员邀请 |
| 指定成员库负责人 | 本库 | 可以 | 本库全部文档 | 可以 |
| 编辑成员 | 已加入的库 | 可以 | 本人创建的文档 | 不可以 |
| 只读成员 | 已加入的库 | 不可以 | 不可以 | 不可以 |
| 未加入者 | 不可以 | 不可以 | 不可以 | 不可以 |

管理员、知识库管理员也遵守空间访问规则，不能读取他人的个人库或未加入的共享库。成员被移除后，即使是原文档作者也失去访问权限。

### 添加成员与转让

负责人打开「空间设置 → 成员管理」，搜索启用成员并添加。新增默认只读，可调整为编辑，也可以移除。负责人只能转让给已经加入且启用的成员，转让后原负责人保留编辑成员身份。个人库不支持邀请、转让或删除。

### 什么时候已经保存

- 编辑已有文档时，停止输入约1秒后自动保存内容，不增加版本；点击「保存文档」成功后才增加一个版本。新文档首次保存为v1。
- 自动保存保留所选文档状态；已发布文档的修改保存后，有访问权限的成员会看到更新。
- 新文档须点击「保存文档」正式创建。重要内容离开前确认保存状态，必要时点击「下载草稿」另存。

### 断网与版本冲突

网络失败时，编辑器保留本地草稿并重试；网络恢复后或点击「重试同步」继续保存。重新登录同一账号、使用同一浏览器进入原编辑入口，可恢复尚未同步的草稿。草稿不会跨设备自动恢复，清除网站数据会将其删除。

其他窗口或成员已同步新内容时，编辑器暂停同步以避免覆盖，包括对方尚未生成新版本的自动保存。先「下载草稿」，再「读取最新版本」，核对合并后保存。权限被撤销时不能继续读取或同步，相关编辑窗口和草稿会清理，请及时联系负责人。

## 10 用户部门与角色

### 管理员添加成员

1. 打开「用户与权限」，点击添加成员入口，填写姓名、用户名、部门和初始密码。
2. 按职责勾选一个或多个角色，再保存。初始密码同样须为12至128位，并满足四类字符至少三类。
3. 根据工作需要，在「项目管理」为成员分配具体项目岗位。
4. 需要飞书通知时，为该成员配置当前飞书应用下的open_id。
5. 单独将账号交给成员，提醒其首次使用修改密码。

成员列表支持姓名、用户名或部门搜索，以及部门、角色、状态筛选和每页10、20或50条分页。点击「管理角色」调整角色，点击「停用」或「启用」控制账号状态。

### 当前角色分类

| 分类 | 角色 |
| --- | --- |
| 基础与系统 | 申请人 管理员 License管理者 知识库管理员 |
| 审批与执行 | 部门负责人 运维负责人 管理者 运维人员 测试人员 商业化负责人 项目经理负责人 技术负责人 智能体开发负责人 |
| 项目与业务 | 销售／售前 项目经理 智能体开发 产品开发 |

角色可以多选。审批人由已发布的流程及成员、岗位条件解析；勾选角色本身不会给某人生成全部审批任务。

### 部门与业务负责人联动

| 本部门负责人 | 可以维护的成员角色 |
| --- | --- |
| 商业化负责人 | 销售／售前 |

## 11 审批流程配置

管理员进入「系统配置 → 审批流程」，分别配置资源申请、变更管理、私有化交付和License授权。修改草稿不会立即改变正式审批，需发布新版本。

### 添加审批节点

1. 选择业务类型，点击「＋ 审批节点」，填写能说明审批职责的节点名称。
2. 选择处理人来源，并选择对应成员或岗位。
3. 选择全部同意、任意一人同意或任意N人同意；选择N人时填写人数。
4. 使用「上移」「下移」调整顺序，删除不需要的普通节点。
5. 保留业务末节点：普通业务为执行回填，License为最终审批并生成密钥。

### 如何选择处理人来源

| 来源 | 匹配方式 | 适用情况 |
| --- | --- | --- |
| 固定成员 | 手动多选启用成员 | 固定审核团队 |
| 项目岗位 | 按关联项目中的指定岗位匹配 | 不同项目由各自负责人审批 |
| 申请归属部门岗位 | 按归属部门及角色匹配 | 部门或职能负责人审批 |

固定成员多选框可用Ctrl键逐个选择；Mac使用Command键。多人审批人数必须与实际合格处理人数匹配，申请人本人和停用成员不参与审批匹配。

### 部门匹配规则

普通成员申请按申请人所属部门匹配；管理员申请按关联项目所属部门匹配。使用「部门负责人」时，优先匹配该部门显式授予部门负责人角色的合格成员；没有时，匹配该部门的相应业务负责人。若只希望商业化、项目经理、技术或智能体开发负责人审批，可直接选择对应负责人角色。

### 执行节点与License末节点

执行回填节点要求合格的运维人员。License末节点使用固定成员并支持多选，可设置全部、任意一人或任意N人同意。最终密钥可见范围仍是申请人和实际触发生成的最后一名审批人，不会扩展到所有候选人。

**没有合格处理人时。** 检查账号启用状态、成员角色、项目岗位、所属部门和申请人排除规则；不要仅通过增加人数绕开缺失的岗位配置。

## 12 条件分支与流程发布

### 添加条件分支

1. 在流程中点击「＋ 条件分支」，填写分支名称。
2. 为普通分支选择「全部满足」或「任一满足」，再添加条件。
3. 选择环境、资源类型、审批归属部门等当前业务可用字段。
4. 设置「等于」「属于」或「不属于」及条件值。多值用英文逗号分隔。
5. 在各分支内添加所需审批节点，保留最后的默认分支。

分支从上到下判断，首个匹配的分支生效；均不匹配时进入默认分支。分支内步骤结束后，继续后续公共节点。条件值须与实际字段一致，例如“生产”环境不能写成随意缩写；资源类型应使用目录的稳定标识。

### 配置示例

某类申请按环境区分审批：生产环境进入额外负责人审批；默认分支处理其他环境；分支完成后统一进入运维回填。该示例说明配置方法，不代表平台强制采用此审批链。

### 校验预览和发布

1. 点击「保存草稿」，保存当前编辑内容。
2. 点击「校验」，修正页面提示的结构、节点和人数问题。
3. 在「路径预览」选择实际申请人、关联项目并填写条件样例，点击「计算预计路径」。
4. 核对命中分支、各节点名称、具体处理人和通过人数。预览不会创建待办或发送飞书通知。
5. 至少检查一组满足条件和一组走默认分支的样例，确认后点击「发布新版本」。

结构校验通过不等于所有项目都具备合格审批人。发布前仍应使用实际账号和项目预览，尤其是管理员申请和多人阈值场景。

### 已发布版本和待办转交

已发布版本只读。需要沿用旧配置时，选择版本，点击「复制此版本到草稿」，修改后再次保存和发布。新申请和驳回重提使用新版本，在途单据继续旧版本。

处理人停用、权限撤销或无法继续处理时，管理员在单据流程详情选择待处理任务，指定合格的新处理人并填写原因，点击「转交待办」或「转交」。新处理人不能是申请人，且须符合原节点的角色和部门约束。转交会保留记录，不能用来改写已完成的审批意见。

## 13 资源类型与飞书通知

### 配置资源类型和规格

管理员打开「系统配置 → 资源类型」，点击新增入口，填写资源类型名称、稳定标识和用途说明，设置为使用中。再为该类型添加申请规格字段，点击「保存资源目录」。

- 类型稳定标识以英文字母开头，可含字母、数字、下划线和短横线，最多30位，保存后不可修改。
- 每个字段填写名称、字段标识、填写方式、输入提示和是否必填。字段标识以小写字母开头，可含小写字母、数字和下划线，最多40位。
- 填写方式支持单行文本、多行文本、数字、下拉选项；下拉选项每行一个。
- ECS可配置CPU、内存等字段；APIKEY可配置厂商下拉选项。字段名称建议包含单位。
- 保存后用申请表检查实际效果；不再使用的类型可停用，历史申请继续保留原规格。

### 配置飞书应用

1. 在飞书开放平台创建企业自建应用，启用机器人，申请「im:message:send_as_bot」权限，发布应用并确认接收成员在可用范围内。
2. 在「系统配置 → 飞书通知」填写App ID、App Secret及平台访问地址，开启通知并保存。
3. 在「用户与权限」找到申请人、审批人等接收成员，为其配置本应用下的open_id并保存。
4. 返回系统配置，点击「检查已保存的应用凭据」。再结合实际流程事件检查「通知记录」和接收结果。

open_id用于识别接收人，须由飞书应用管理员通过本应用可用的通讯录接口或官方API调试台获取。它不是手机号、平台用户名或App ID，也不能直接使用另一个应用的open_id。若没有查询权限，请飞书管理员协助获取。

### 保存后的表现

open_id保存后以掩码展示；需要更换时重新填入完整值。App Secret留空会保留已有密钥。凭据检查通过只表示应用凭据有效，还需验证接收成员标识、应用范围和实际发送结果。

通知会提醒申请人提交和进度，提醒当前处理人办理，并在驳回或流程完成后提醒申请人。平台访问地址应填写接收人能访问的正式地址，用于生成业务链接。密码和License Key须登录平台按权限查看。

## 14 通知记录与操作日志

### 查看通知记录

点击通知入口，或由管理员从左侧「通知记录」进入。非管理员仅查看发送给自己的记录；管理员可查看全部发送记录。可搜索接收人或内容，按状态筛选，并选择每页10、20或50条。

| 状态 | 含义及处理 |
| --- | --- |
| 排队中 | 等待后台发送，关注后续状态及下次重试时间 |
| 已发送 | 平台调用飞书发送成功，仍应由接收人确认收到 |
| 失败 | 查看具体错误，检查权限范围标识或网络后再重试 |
| 待配置 | 检查通知开关 App凭据和接收人的open_id |

管理员可对失败、待配置或页面允许处理的历史排队记录点击「重试」。先修复配置再重试，不需要反复创建业务申请来触发提醒。飞书是否收到消息不代替平台的实际审批状态，处理结果以单据详情为准。

### 查询业务操作

管理员进入「操作日志」，默认查看「业务操作」。按操作人、单据类型、动作、时间和关键词组合查询，再打开详情核对操作对象、发生时间及字段变化。

**常见用途。** 查清谁创建了某张申请、谁修改内容、谁审批或驳回、谁完成回填、谁删除单据，以及谁调整成员或转交待办。日期与时间按页面标注查看，日志时间显示为北京时间。

### 排查失败请求

切换到「接口访问与异常」，按时间、人员和结果查找失败尝试。向管理员提供单据编号、操作时间和页面错误原文，有助于缩小查询范围；不要只提供“打不开”或“失败了”。

### 日志和隐私

新增知识库审计不记录文章正文，知识库相关日志还会按空间访问权限过滤。管理员能查看操作日志，也不意味着能通过日志读取他人的个人知识库或未加入空间的内容。

账号密码、应用密钥和License Key不应出现在普通备注或求助截图中。日志用于追溯操作，业务详情仍需按对应单据权限访问。

## 15 删除停用与资料保留

不同对象的处理方式不同。删除单据、停用项目、停用账号和移除知识库成员会产生不同结果，操作前请核对对象名称和编号。

| 对象 | 可操作人员 | 处理结果 |
| --- | --- | --- |
| 资源 变更 私有化交付单据 | 申请人或管理员 | 隐藏业务记录，保留审批历史和操作日志 |
| License申请 | 申请人 管理员或License管理者 | 隐藏申请记录，保留追溯记录 |
| 项目 | 管理员 | 不可删除，可停用，不能用于新申请 |
| 成员账号 | 管理员 | 停用后不能正常登录和处理任务 |
| 指定成员知识库 | 库负责人 | 移入回收站，所有成员失去访问权限 |
| 个人知识库 | 本人维护基本信息 | 不支持删除 邀请或转让 |

### 删除业务申请

打开有管理权限的单据详情，找到「删除单据」或删除入口，核对单据编号并再次确认。审批人仅凭被分配任务并不自动获得删除权。

「我的审批」中只有对原单据具备删除权限时才显示删除入口。此操作删除的是原业务单据，不是单独删除自己的审批意见；删除后相关待办不再出现在正常待办列表。业务单据当前没有前台恢复入口，请谨慎确认。

删除申请不会自动撤销已实际开通的云资源、已执行的系统变更或已使用的License。需要回收资源、回退变更或处理授权时，应另行安排实际操作。

### 删除和恢复知识库

负责人进入「空间设置」，点击「删除知识库」，输入完整库名后确认。文档、版本及成员关系保留，但成员无法继续访问。负责人可从知识库页面「回收站」恢复，原文档和成员权限一并恢复。恢复前请检查原成员是否仍适合保留访问权限。

### 成员离岗时

管理员先检查该成员的待处理审批和执行任务，必要时转交给合格成员；再处理项目岗位、知识库负责人及共享成员关系，最后停用账号。账号停用不会自动替换原待办处理人，也不应靠多人共用原账号完成交接。

## 16 常见问题与交接检查

### 为什么不能申请或处理审批

- **项目不可选。** 检查项目是否启用、账号是否有相应角色和项目岗位。仅能维护部门项目，不代表能申请该项目。
- **显示没有合格审批人。** 请管理员检查流程来源、项目岗位、所属部门、账号启用状态和人数阈值；同时排除申请人自己。
- **管理员的我的审批为空。** 只有分配给本人的待处理任务才显示，查看业务详情和审批任务分配是两种权限。
- **任务存在但无法处理。** 可能是账号或岗位权限变化，或其他人已经达到通过阈值。刷新单据；确需调整时由管理员转交待办。
- **流程发布后旧单据未变化。** 在途单据继续原版本，新申请或驳回重提才使用新版本。

### 为什么看不到资料或结果

- **License已生成却看不到Key。** 仅申请人和实际触发生成的最终审批人可见；管理者和其他会签人不自动可见。
- **看不到同事的知识库。** 请该库负责人将你加入指定成员库；个人库仅本人可见，管理员也不能越权读取。
- **知识库能看不能编辑。** 只读成员不能写作；编辑成员只能修改本人文档，负责人可编辑库内全部文档。
- **知识库一直未保存。** 先检查必填项和保存提示；下载草稿，再检查网络或按提示重试。新文档仍需首次点击保存。
- **附件打不开或上传失败。** 检查格式与20MB限制，确认自己是创建人；预览失败时下载原文件。持续失败交管理员检查存储和转换服务。
- **飞书未收到提醒。** 在通知记录查看状态，请管理员检查当前应用open_id、机器人权限、发布版本及成员可用范围。

### 交接前最后检查

申请人确认单据编号、项目和附件已保存；审批人确认意见已经提交；执行人员确认结果及必要方案已经回填；文档作者确认「已保存」，必要时下载草稿。负责人交接时，确认项目岗位、待办转交和知识库成员权限已同步处理。

遇到无法解决的问题，请向管理员提供模块名称、单据编号或文档标题、操作时间、账号名及错误原文。提交截图前遮盖敏感信息。
